Tank Farming SCADA: how to run the project

A field guide for delivering PCS 7 automation for a Fujairah tank terminal, from P&ID freeze to hot commissioning.

Control system

Siemens SIMATIC S7-410-H redundant AS on PCS 7, with ET 200SP HA / ET 200M Remote I/O panels in safe and hazardous zones.

Server and client layer

Redundant OS server pair (A/B), Engineering Station, multi-client Operator Stations, OpenPCS 7 and Historian.

Network

Dual redundant fiber rings on SCALANCE X switches (MRP, PRP or HSR) monitored by SINEMA Server with SNMP diagnostics.

Scope

PCS 7 system and marshalling cabinets, Remote I/O panels, fiber network panels, radar ATG with multi-spot temperature and water bottom, SIL-rated overfill protection, MOV links (Modbus, PROFIBUS, PROFINET) and jetty/manifold interlocks.
